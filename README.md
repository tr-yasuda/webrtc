# webrtc

WebRTC プラットフォームの仕様をまとめています。コードは TypeScript の [Browser SDK](packages/browser-sdk) と Rust の [STUN](crates/stun) の最小構成です。

構成を知るには [全体構成](docs/platform/overview.md)、各コンポーネントの詳細を調べるには [仕様一覧](docs/README.md) を参照してください。

## 開発環境

開発に参加する場合は、[セットアップと検証の手順](AGENTS.md#開発と検証)を参照してください。
